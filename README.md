# NetlyHub WhatsApp Bot

Asistente virtual con IA para WhatsApp Business.
Responde clientes automáticamente 24/7.

## Stack
- Node.js + Express
- Twilio WhatsApp Business API
- OpenAI GPT-4o-mini
- Railway (deploy)

## Variables de entorno
OPENAI_API_KEY=
TWILIO_ACCOUNT_SID=
TWILIO_AUTH_TOKEN=

## Instalación
npm install
node bot.js
